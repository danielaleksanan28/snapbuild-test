# Снэпбилд · конструктор иллюстраций

Тестовое задание на позицию Junior AI Developer (Снэпбилд, «Очень»).

**Сервис:** https://danielaleksanan28.github.io/snapbuild-test/
**Автор:** Даниэль Алексанян

Веб-сервис автоматически собирает векторные композиции из готовой библиотеки иллюстраций.
Новые объекты не генерируются и не перерисовываются: в композицию попадают только исходные SVG из Figma
(10 объектов × главная/фоновая версия × размеры L и S).

Все три файла — это прямой экспорт из сервиса, без ручной доработки.

## Что умеет

**Два сценария сборки**
1. **По заголовку или метафоре.** Пишете, например, «Как накопить на отпуск». Сервис разбирает текст,
   подбирает подходящие объекты (монета, кошелёк — «деньги»; лампа, цветы — «отдых и уют»), показывает,
   почему выбрал каждый, и раскладывает их.
2. **По списку.** Пишете «лампа, книга, ручка, фон: наушники» — сервис узнаёт объекты в любой форме слова
   («лампу», «книги»), а для неизвестных честно пишет, что такого объекта в библиотеке нет.

**Работа с SVG и библиотекой**
- библиотека из 40 SVG-файлов, нарезанных из исходного Figma-файла скриптом (см. «Архитектура»);
- векторная структура, цвета и пропорции объектов сохраняются: на холсте меняется только положение, поворот и масштаб.

**Сборка композиции**
- три раскладки по примерам из Figma: «Под заголовок» (оставляет место под текст, показывает его рамкой),
  «Со смещением» (ряд с перекрытием и сдвигом по высоте), «Собранно» (плотная группа);
- «Ещё вариант» — другая раскладка тех же объектов;
- объекты можно добавлять из библиотеки, перетаскивать, вращать (круглая ручка, с Shift — шагом 15°),
  масштабировать (угловая ручка), дублировать, удалять, менять порядок слоёв, переключать главная ⇄ фоновая версия;
- выбор размера иллюстраций **L / S** — объекты подменяются на версию нужной детализации, оставаясь на своих местах;
- форматы: 1200×630, 1080×1080, 1080×1350, 1920×1080;
- отмена и повтор (Ctrl+Z / Ctrl+Shift+Z), горячие клавиши: Delete, Ctrl+D, `[` `]`, стрелки.

**Цветовые схемы**
- три схемы из Figma: Лаванда, Персик, Мята;
- загрузка своей палитры из JSON (пример: [`library/palette-example.json`](library/palette-example.json)) —
  вся композиция перекрашивается автоматически;
- соблюдается правило из библиотеки: цвета фона можно использовать в объектах, а цвета объектов в фонах — нельзя
  (фон холста и фоновые объекты берут цвета только из «фоновой» части палитры).

**Экспорт**
- «Скачать SVG» — чистый векторный файл: каждый объект — отдельная группа с понятным id (`book-main-3`),
  без растровых вставок и служебных атрибутов. Файл открывается и редактируется в Figma / Illustrator.

## Архитектура

Сервис статический (HTML + CSS + JS без фреймворков и сборки), поэтому работает с GitHub Pages и открывается по ссылке.

```
app/
├── index.html, style.css, app.js     интерфейс и логика
├── library/
│   ├── L/*.svg, S/*.svg               20 объектов в каждом размере (главные + фоновые)
│   ├── library.json                   каталог: объект, вид, размер, габариты, цвета, слой в Figma, теги
│   └── palette-example.json           пример своей палитры
├── tools/
│   ├── build_library.py               нарезка библиотеки из SVG-экспорта Figma
│   └── dev_server.py                  локальный сервер (умеет сохранять примеры)
└── examples/                          примеры собранных композиций
```

**Хранение.** Исходник — экспорт фреймов «Размер L» и «Размер S» из Figma в SVG с атрибутом id
(в нём имена слоёв). `tools/build_library.py` находит группы объектов по именам слоёв, определяет главная это
или фоновая версия (фоновые состоят только из двух «фоновых» цветов), считает точные габариты
(библиотека `svgelements`) и сохраняет каждую группу в отдельный файл **без изменений**, пересчитывая только `viewBox`.
Технические id из Figma удаляются, чтобы при сборке нескольких объектов не было конфликтов.
Результат описан в `library.json`.

**Извлечение.** Сервис загружает `library.json`, а SVG объектов — лениво, только когда объект нужен, и кэширует.
При загрузке каждый цвет внутри объекта помечается своей **ролью** в палитре (`bg1…bg3`, `obj1…obj3`, `ink`, `paper`) —
объекты в Figma нарисованы в схеме «Лаванда», поэтому каждый исходный цвет однозначно соответствует роли.

**Переиспользование.** Объект на холсте — это клон исходной группы внутри `<g transform="translate rotate scale">`.
Одна и та же группа может стоять на холсте сколько угодно раз. Перекраска — замена цвета по роли, поэтому
любая палитра (в том числе загруженная) применяется ко всей композиции мгновенно и без потерь.
Масштаб хранится относительно размера L, поэтому при переключении L ⇄ S объект занимает то же место.

**Подбор по смыслу.** Словарь ассоциаций: основы слов → объекты с весами
(например, «накоп», «бюджет», «зарплат» → монета, кошелёк). Прямое упоминание объекта в тексте весит больше.
Берутся 2–4 самых подходящих объекта, следующий по рейтингу становится фоновым. Если совпадений нет,
сервис берёт универсальный набор и прямо об этом пишет. Словарь работает в браузере, без сервера и ключей API.

**Раскладка.** Каждый шаблон задаёт область холста (для широких форматов место под заголовок слева,
для квадратных и вертикальных — сверху). Объекты сохраняют исходные пропорции друг к другу
(совсем мелкие, вроде монеты, немного увеличиваются, чтобы читаться), расставляются по ячейкам или в ряд,
затем раздвигаются, если перекрываются слишком сильно. Порядок слоёв — изометрический:
кто ниже на холсте, тот ближе к зрителю. Фоновые объекты ставятся позади, в самое свободное место.

## AI-инструменты

- **Claude Code (Claude)** — основной инструмент: вместе с ним писал код сервиса и скрипт нарезки, разбирал
  структуру SVG из Figma (имена слоёв, цвета, какой слой какому объекту соответствует), составлял словарь ассоциаций,
  тестировал сервис в браузере (сборка, перекраска, экспорт, отмена, мобильная версия).
- Сам ставил задачи, принимал решения по устройству сервиса и проверял результат на каждом шаге.

## Ограничения и что сделал бы дальше

- Подбор по смыслу сейчас на словаре — он быстрый и предсказуемый, но не понимает сложные метафоры.
  Следующий шаг — подключить LLM (Claude) через небольшой серверный прокси: модель получает каталог объектов
  с описаниями и возвращает список объектов и пояснение; словарь остаётся запасным вариантом.
- Раскладка — эвристика по образцу примеров из Figma. Можно добавить «смысловые связки»
  (телефон лежит на книге, пазл на телефоне — как в примерах) и больше шаблонов.
- Плагин для Figma на той же логике: библиотека уже живёт в Figma, сборка шла бы прямо в файл.

## Запуск локально

```bash
cd app
python -m http.server 8000
# открыть http://localhost:8000
```

Пересобрать библиотеку из новых экспортов Figma:

```bash
pip install svgelements
python tools/build_library.py путь/к/Размер-L.svg путь/к/Размер-S.svg
```

Иллюстрации принадлежат «Очень» и используются только для этого тестового задания.
